# 签名图片与 Word 签批说明

## 签批在哪些报告出现

- **项目信息页（封面）**：在生成**项目总报告**等包含 `generateProjectInfoPage` 的 Word 中，当项目状态为 **`Completed`（已完成）** 时，会显示 **批准 / 审核 / 编写** 三行签批。
- 人员姓名来自项目上的 **无损（NDT）与理化（Chem）** 对应字段（如 `writerNdt` / `writerChem` 等）。

## 签名图片目录与命名

- 配置项：`signatures.dir`（默认 `./signatures`，相对路径相对**应用启动时工作目录**）。
- 在目录下为每位需要显示手写签名的人员放置图片，**文件名 = 姓名 + 扩展名**，例如：`肖乐园.png`。
- 支持扩展名：`.png`、`.jpg`、`.jpeg`（大小写均可）。
- **姓名须与系统中填写一致**（含全角/半角、空格）。程序会先做 `trim`，并额外尝试**去掉姓名中所有空白字符**后的文件名（例如 `张 三.png` 与 `张三.png` 会各尝试一次）。

## 无签名文件时

- 若找不到对应图片，或图片插入失败，Word 中会**回退为打印该人员姓名**（不再留空），并在日志中输出 **WARN**（含签名目录路径、未找到的姓名）。

## 运行环境

- 部署后请将 `signatures` 目录放到与 `signatures.dir` 一致的位置，或改为绝对路径指向共享盘上的签名库。
